## The four workstreams

1. **dApp approval + signing reroute (DEVNET-safe, fully buildable now).** The shipped wallet writes its 64-byte secret to `chrome.storage.session["helio:secret"]`, but the dApp path delegates to a dead `extension-storage` wallet state that onboarding never populates → `signSerializedDappTransaction` has no key → 60s timeout, and `src/App.tsx` has no approval UI. Fix: **sign in the background service worker** (Option A) using the session secret, popup is approval-only (sends `{requestId, decision}`, never sees keys), key zeroed in a `finally`. Reuse existing `assertTrustedSender`, parking, and 60s-timeout machinery. No chain needed to verify.

2. **web3.js v1 → v2 (@solana/kit) — first safe leaf migration (buildable now).** Kit is a total breaking change. **Anchor 0.32 is hard-locked to web3.js v1** → everything in `src/lib/helio-program.ts` (sweep, staking, shipped send path) **must stay on v1** until a Codama/Kit-native client replaces the Anchor TS client. First migration target: the **pure RPC read path** in `@helio/api` `HelioRpcClient` (`getBalance`/`getParsedTokenAccountsByOwner`/`getLatestBlockhash`/`getAccountInfo`) — zero Anchor, zero signing, zero key material. Bridge with `@solana/compat`. Land the rate-limit + URL-scheme-allowlist security mandates inside the new Kit transport wrapper.

3. **Jupiter swap (MAINNET) — buildable now, verifiable only on mainnet.** New `JupiterSwapClient` in `@helio/api`. Routes are `${host}/swap/v1/{quote,swap}` (NOT legacy `/v6`). Host `lite-api.jup.ag` (no key) or `api.jup.ag` (`x-api-key`). `/swap` returns a base64 **v0 VersionedTransaction** → `VersionedTransaction.deserialize` → simulate (`replaceRecentBlockhash:true, sigVerify:false`, fail-closed) → `.sign([kp])` → zero key → `sendRawTransaction(skipPreflight:true)` → confirm via `lastValidBlockHeight`. **Never replace the blockhash** (breaks Jupiter's pre-signed WSOL signers). Decimals via Jupiter `tokens/v2` with `getMint()` fallback; build atomic amounts with BigInt, never float. Dedicated **mainnet** Connection (single exception to Helio's devnet default — Jupiter has no devnet liquidity).

4. **AutoYield on-chain DeFi — buildable now, verifiable only on devnet (after deploy).** New Anchor instruction `deploy_to_protocol` (+ symmetric `withdraw_from_protocol`). Recommended protocol: **Meteora Dynamic Vault** (`24Uqj9JCLxUeoC3hGfh5W3s9FM9uCHDS2SG3LYwBpyTi`, same id mainnet+devnet) — 7-account, no-oracle, no-obligation deposit. Fallback if no seeded devnet vault for the test mint: a **Helio-owned mock yield vault** (second program, identical 7-account / `(amount, min_lp)` shape) so the CPI-signing + slippage + `reload()` accounting + simulation path is fully exercised on devnet now. Add `PROTOCOL_MOCK=1` / `PROTOCOL_METEORA=2`, relax `config.rs::validate()` + `utils.rs::protocol_mask()`. Run `program_autofixer` to fixpoint before deploy.
